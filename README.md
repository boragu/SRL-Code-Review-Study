# SRL-Code-Review-Study
SRL 연구실 학부연구생 Kaggle &amp; DACON 데이터 분석 및 머신러닝 코드 리뷰 스터디

# 🏆 SRL Data Science & ML Competition Study

> **인천대학교 SRL 학부연구생 데이터 분석 및 머신러닝/딥러닝 코드 리뷰 스터디 레포지토리입니다.**

Kaggle 및 DACON의 경진대회 주제를 선정하여 각자 문제를 해결하고, 서로의 접근 방식과 코드를 리뷰하며 함께 성장하는 것을 목적으로 합니다.

---

## 🎯 스터디 목표
1. **데이터 전처리 및 모델링 역량 강화**: 다양한 도메인의 데이터를 경험하고 문제 해결 능력을 기릅니다.
2. **코드 리뷰를 통한 파이프라인 확장**: 동료의 코드를 리뷰하며 본인이 생각하지 못한 아이디어나 전처리/모델링 기법을 배웁니다.
3. **가독성 높고 재사용 가능한 코드 작성**: 실험에 그치지 않고 깔끔한 프로덕션 레벨 코드 작성 및 버전 관리를 연습합니다.

---

## 📂 폴더 구조 (Directory Structure)

각 주차/주제별로 폴더를 생성하고, 내부에서 본인 이름(또는 닉네임) 폴더를 생성하여 작업합니다.

```text
.
├── README.md
├── .gitignore
├── [주제_이름_ 또는_주차] (예: 01_Titanic / 02_Dacon_AIAudio)
│   ├── README.md                 # 해당 대회/주제 설명 및 베이스라인 공유
│   ├── [본인이름_또는_GitHubID]   # 개인별 작업 공간
│   │   ├── README.md             # 개인별 제출 요약 (전처리 기법, 모델, 결과 CV/LB 스코어 기록)
│   │   ├── solution.ipynb        # 실험 및 분석 노트북
│   │   └── src/                  # 모듈화된 파이썬 코드 (선택)
│   └── [본인이름_또는_GitHubID]
└── ...
